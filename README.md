# TON 618 — English, with gravity

**Живая версия:** <https://fastop06.github.io/ton-618/>

Одностраничный сайт школы английского с кинематографичным интро: стена английских
слов висит в темноте, две волны проходят по ней, буквы отрываются и закручиваются
в чёрную дыру, раскаляясь от красного к оранжевому и жёлтому, складываются в
аккреционный диск и вытягиваются в линии. Финальный кадр с **TON 618** остаётся
на месте и становится главным экраном сайта: страница прокручивается вниз из него.

## Запуск

Сборка не нужна. Достаточно открыть `index.html` в браузере.

Если нужен локальный сервер:

```bash
cd ton-618
python3 -m http.server 8000
```

Затем открыть <http://localhost:8000>.

## Интро

- Длительность — около 10 секунд, после чего кадр замирает и открывается сайт.
- Стена из ~1300 английских слов; буквы — отдельные частицы, поэтому слова
  распадаются при коллапсе.
- Две волны → дыра → буквы падают по спирали, нагреваются и вытягиваются в линии →
  аккреционный диск и фотонное кольцо → дрейф камеры → титул → финальный кадр.
- Пропустить: кнопка **Skip intro**, клавиша `Esc` или клик по фону. Все три
  варианта сразу показывают финальный кадр.
- При `prefers-reduced-motion: reduce` интро не проигрывается: сразу показывается
  финальный кадр с титулом.
- Страховка: через 15 секунд интро принудительно закрывается, даже если кадры
  остановились.

## Структура

```
index.html        — разметка страницы и интро
styles.css        — дизайн-система, адаптив, анимации
intro.js          — canvas-движок интро (слова, волны, коллапс, чёрная дыра, финальный кадр)
app.js            — навигация, появление секций, карточки слов, озвучка, квиз, FAQ
audio/            — готовые клипы произношения для карточек слов
tools/build-audio.sh — генерация этих клипов
```

## Озвучка слов

Карточки проигрывают заранее записанные клипы из `audio/` через Web Audio.
Клип получен из системного голоса macOS (`say`), в конце у него плавное
затухание и короткий хвост тишины — поэтому звук не обрывается щелчком.
Если клип не загрузился, используется голос браузера.

Пересобрать клипы (нужны macOS, `say` и `ffmpeg`):

```bash
bash tools/build-audio.sh
```

Скрипт берёт слова прямо из `app.js`, поэтому новые карточки подхватятся сами.

## Что можно настроить

- **Таймлайн интро** — объект `T` в начале `intro.js` (`wave1`, `wave2`, `hole`,
  `collapse`, `drift`, `title`, `freeze`, `ready`).
- **Словарь карточек** — массив `WORDS` в `app.js` (уровни A1–C1).
- **Цвета и типографика** — CSS-переменные в `:root` в `styles.css`.
- **Вопросы квиза** — массив `QUIZ` в `app.js`.

Шрифты подключаются с Google Fonts (Instrument Serif и Inter); при отсутствии
интернета браузер использует системные запасные шрифты.
