# TON 618 — English, with gravity

**Живая версия:** <https://fastop06.github.io/ton-618/>

Одностраничный сайт школы английского с кинематографичным интро: стена английских
слов висит в темноте, две волны проходят по ней, буквы отрываются и закручиваются
в чёрную дыру, раскаляясь от красного к оранжевому и жёлтому, складываются в
аккреционный диск и вытягиваются в линии. Камера уходит вправо, в пустоте
появляется **TON 618**, и сайт открывается.

## Запуск

Сборка не нужна. Достаточно открыть `index.html` в браузере.

Если нужен локальный сервер:

```bash
cd ton-618
python3 -m http.server 8000
```

Затем открыть <http://localhost:8000>.

## Интро

- Длительность — около 12,5 секунд (с панорамой в сайт).
- Стена из ~1300 английских слов; буквы — отдельные частицы, поэтому слова
  распадаются при коллапсе.
- Две волны → дыра → буквы падают по спирали, нагреваются и вытягиваются в линии →
  аккреционный диск и фотонное кольцо → дрейф камеры вправо → титул → панорама.
- Пропустить: кнопка **Skip intro**, клавиша `Esc` или клик по фону.
- При `prefers-reduced-motion: reduce` интро отключается, сайт открывается сразу.
- Страховка: через 15 секунд интро принудительно закрывается, даже если кадры
  остановились.

## Структура

```
index.html   — разметка страницы и интро
styles.css   — дизайн-система, адаптив, анимации
intro.js     — canvas-движок интро (слова, волны, коллапс, чёрная дыра, панорама)
app.js       — навигация, появление секций, карточки слов, озвучка, квиз, FAQ
```

## Что можно настроить

- **Таймлайн интро** — объект `T` в начале `intro.js` (`wave1`, `wave2`, `hole`,
  `collapse`, `drift`, `title`, `pan`).
- **Словарь карточек** — массив `WORDS` в `app.js` (уровни A1–C1).
- **Цвета и типографика** — CSS-переменные в `:root` в `styles.css`.
- **Вопросы квиза** — массив `QUIZ` в `app.js`.

Шрифты подключаются с Google Fonts (Instrument Serif и Inter); при отсутствии
интернета браузер использует системные запасные шрифты.
